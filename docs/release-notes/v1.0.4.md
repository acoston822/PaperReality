# PaperReality 1.0.4

This update adds native iPad support and improves controller navigation in the
iOS settings interface. These notes cover changes since PaperReality 1.0.3.

**Download:** `PaperReality-v1.0.4-unsigned.ipa` below. Sign and install it with
AltStore, Sideloadly, or your own signing certificate. Requires iOS/iPadOS 16.3
or later. The game and HD texture packs are supplied by the user.

## Changes

- Added native iPad support alongside iPhone support. Earlier releases declared
  iPhone-only support, causing iPadOS to use compatibility mode. This fixes the
  reported inability to fill the iPad display with Stage Manager enabled.
- Removed the bottom controller help strip from settings. Controller navigation
  and the focus outline remain available.
- Fixed controller focus outlines on native dialog actions such as OK, Cancel,
  and Select Save. The outline now follows the full button instead of only the
  text, including cases where a dialog heading has the same text as an action.

The app remains **PaperReality** with bundle ID `com.damien.paperreality`.

## Validation

- Build 117's iPad fullscreen fix was reported working on the affected iPad.
- An iPadOS 26.2 simulator window test verified native iPad mode and a full
  1376 × 1032 canvas with Stage Manager selected. The system fullscreen button
  was not available to automation; its interaction was not simulator-verified.
- UIKit dialog tests covered side-by-side actions, stacked actions, disabled
  actions, and matching heading/action text.
- Release packaging checks the IPA archive, iPhone/iPad support, app name,
  bundle ID, version, and build number.
