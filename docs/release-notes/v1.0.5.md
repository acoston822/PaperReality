# PaperReality 1.0.5

This update improves save-card transition rendering and includes PaperBoat's
latest script-buffer and soft-reset fixes. These notes cover changes since 1.0.4.

**Download:** `PaperReality-v1.0.5-unsigned.ipa` below. Sign and install it with
AltStore, Sideloadly, or your own signing certificate. Requires iOS/iPadOS 16.3
or later. The game and HD texture packs are supplied by the user.

## Changes

- Fixed rotating window geometry used in save-card transitions. Queued frames
  retain their own vertices, and all four corners now use valid vertex indices.
  This addresses two defects that could corrupt the transition geometry.
- Included PaperBoat #278: fixed 64-bit script-buffer overruns in Huff N. Puff,
  Fake Bowser/Koopa Bros. and Bandit code.
- Clear scripts and workers when performing a soft reset.

The app remains **PaperReality** with bundle ID `com.damien.paperreality` and
native iPhone/iPad support. No new settings are added. The experimental ground leaf
rendering change and render diagnostics are excluded from this release;
the known leaf flicker remains unresolved here. The settings FPS HUD stays off.

## Validation

- The window regression checks production rendering commands for valid corner
  indices, initialized vertices, texture coordinates and queued-frame stability,
  including display-context reuse and 64 panels in one frame. It passes with
  AddressSanitizer enabled.
- The user reported no further save-card flicker while testing 4:3 and Off aspect
  ratios at both 60 and 120 FPS. Because the original symptom was intermittent,
  this does not establish that every possible occurrence is resolved.
- Release packaging checks the IPA archive, iPhone/iPad support, app name,
  bundle ID, version and build number. The normal Release build retains the
  established UIKit, controller, touch, AirPlay and frame-pacing behavior.
