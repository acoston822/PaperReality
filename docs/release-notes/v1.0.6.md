# PaperReality 1.0.6

This update improves shadow and effect rendering and organizes unobtainable
badges in the Save Editor. These notes cover changes since 1.0.5.

**Download:** `PaperReality-v1.0.6-unsigned.ipa` below. Sign and install it with
AltStore, Sideloadly, or your own signing certificate. Requires iOS/iPadOS 16.3
or later. The game and HD texture packs are supplied by the user.

## Changes

- Fixed shadow flicker above 30 FPS, including when Mario stands on floor
  buttons, by preserving transform precision through interpolated shadow draws.
- Applied a small, map-local visual offset to the affected ground leaf in
  Goomba Road 3 to address its flicker.
- Fixed the brief black strip near the Start/menu controls during startup.
- Corrected the partner-upgrade glow's transparency with HD texture packs.
  The correction retains the HD image and dimensions while making its black
  background transparent.
- Adjusted dialogue-frame texture sampling to reduce seams between frame pieces.
- Moved 21 more unobtainable badge entries into the Save Editor's existing
  **Unused** section: ten distinct unused badges and eleven unused duplicate
  copies. The regular section contains the 80 obtainable badge entries.

The app remains **PaperReality**, with bundle ID `com.damien.paperreality` and
native iPhone/iPad support. This release retains build 136's application source;
the version, release notes and release packaging are updated. The separate broad
leaf-rendering experiment is excluded. The Settings timing HUD stays off.

## Validation

- Device testing reported the shadow and targeted leaf fixes working, the
  startup strip removed, and the HD upgrade glow looking better with its
  background corrected.
- Synthetic regressions cover shadow transform precision and queued ownership,
  startup aspect handling, dialogue-frame commands and HD mask alpha handling.
  The dialogue seam still needs broader visual confirmation across game scenes.
- The badge-list audit accounts for 80 obtainable and 29 total unused badge
  entries, preserving the obtainable copies of badges with unused duplicates.
- Release packaging verifies the IPA archive, app identity, version/build number,
  minimum OS and native iPhone/iPad support before publication.

Source details: [1.0.6 source audit](https://github.com/acoston822/PaperReality/blob/v1.0.6/docs/source-changes-v1.0.6.md).
