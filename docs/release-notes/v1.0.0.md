First release of PaperReality, an iOS port of Paper Mario 64 built on [HarbourMasters' PaperBoat](https://github.com/HarbourMasters/PaperBoat) (`develop` at 7f038b85). Everything is the same code as PaperBoat plus the iOS changes below; see [docs/CHANGES.md](https://github.com/acoston822/PaperReality/blob/main/docs/CHANGES.md) for the full list.

**Install:** download `PaperReality-v1.0.0-unsigned.ipa` below, then sign and install it with AltStore, Sideloadly or your own certificate. The game itself is not included: on first launch the app asks for your own copy of the ROM (US SHA1 `3837f44cda784b466c9a2d99df70d77c322b97a0`).

**Heads up:** this is an unsigned community build. Not every feature has been tested on every device yet, so expect rough edges and please report what you find.

## What's in 1.0.0

### iOS app
- Unsigned IPA built automatically by GitHub Actions. The app's bundle ID is `com.damien.paperreality`, so it installs separately from any earlier PaperBoat-based build and starts with a fresh data folder. Each build is stamped with its run number so builds can be told apart.
- Custom red paper boat app icon.
- iOS build fixes: a missing display-list terminator that crashed on the first frame, and a few type casts and texture-lookup fixes.

### First launch
- A greeting asks you to import your game with the Files picker. The app puts it in the right folder, then continues to the asset generation step.
- The first-run boxes and the loading bar are larger on iOS so they are easy to read and tap.

### Touch controls
- Round themed joystick: a clean ring with a small translucent thumb dot in your menu theme color. It can fade out completely when not in use ("Hide Joystick When Idle").
- Redrawn buttons: rounded L and R, a round purple Z, slightly larger C buttons, translucent color fills, and buttons that fill in when pressed.
- Haptic feedback with a choice of strength.
- A setting to show or hide the on-screen D-pad.
- Touch controls hide automatically while a game controller is connected and come back when it disconnects ("Hide With Controller").

### Menus
- Swipe to scroll settings panes and dropdown lists, with flick momentum, instead of dragging the scrollbar.
- More menu scaling options (1.5x, 1.75x, 2.1x, 2.3x) for phone screens.
- The Select/Back button on a controller opens the menu, and controller menu navigation turns on once a controller is detected.

### Mods
- New **Add Files** button on the Mods page: pick `.o2r` files in the Files app and they are copied to the right folder, followed by a Restart Required prompt. Turn on Alternate Assets to use texture packs.

### Performance
- Smoother frame pacing through a Metal present-pacing change in the libultraship fork this build uses.
