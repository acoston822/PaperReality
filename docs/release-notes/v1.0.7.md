# PaperReality 1.0.7

Adds **Key Items** to the native UIKit Save Editor and includes all source changes from releases 1.0.3 through 1.0.6.

**Download:** `PaperReality-v1.0.7-unsigned.ipa` below. Sign and install it with AltStore, Sideloadly, or your own signing certificate. Requires iOS/iPadOS 16.3 or later. Supply your own game and optional texture packs.

## Changes

- Added **Dev Tools → Save Editor → Key Items** with a searchable item catalog, native switches, held-item removal, portraits, and a visible 32-slot capacity count.
- Added distinct names for letter recipients and items that share icons.
- Prevented duplicate additions and capacity overflow, and guarded stale callbacks after slots change or a save unloads.
- Integrated PaperBoat upstream through `da70b9ea5c8efded02680865b4da76a9292e4c50`, including the desktop Key Items tab and macOS build updates.
- Retained the 1.0.6 rendering, startup, dialogue-frame, HD upgrade-glow, and unused-badge fixes, along with the earlier UIKit, controller, touch, and display work.

Key item edits affect the loaded inventory. They do not update story flags or grant rewards. Use **Letters** to edit delivery progression, then save in game to keep changes.

## Validation

- Asset-free checks exercise the production native page's capacity, repeated additions, stale callbacks, unloaded saves, labels, and invalid IDs.
- The release pipeline checks UIKit sources, frame/display timing, model portraits, controller navigation, startup aspect handling, and HD upgrade-orb coverage.
- IPA packaging verifies the archive, version/build number, app identity, minimum OS, and native iPhone/iPad support.
- On-device appearance and game save/reload behavior for the new page still require confirmation.

App identity remains **PaperReality**, `com.damien.paperreality`. The iOS toolchain and libultraship revision are unchanged.
